
JP+ Bridges is a bridge replacement NewGRF for OpenTTD. It is comprised of two separate NewGRFs: JP+ Bridges and JP+ Bridges Extension. This is because the Extension set contains extra features that require JGR Patch Pack and are not supported in standard OpenTTD.

Bridges have limited IDs in OpenTTD, meaning the game only supports 13 bridges. JGRPP adds 3 extra IDs, bringing the total to 16. Therefore, JP+ Bridges should not be loaded with any other bridge set, as the sets will override each other depending on load order.
